# 04. Trees
- A tree is an abstract model of a hierarchical structure.
- It composes of nodes and edges
- Num of nodes = Num of edges + 1

## Components of a tree
1. Root node = the topmost, foundational element in a hierarchical tree structure, serving as the starting point for all data traversal, branching, and operations. It is unique because it is the only node in the tree that has no parent and from which all other descendant nodes emerge
2. Leaf node = nodes without any child nodes

## Types of Trees

### Binary Tree
- Trees which have nodes with no more than 2 children.
- If a node has two children, one child is designated as a left child and the other as a right child.

A binary tree can either be a full binary tree, or a complete binary tree
- Full Binary Tree: every node in the tree except the leaves has exactly two children
- Complete Binary Tree: every level of the tree is completely filled except the last level.

#### Tree Traversals
There are three main ways to traverse (visit) through each node in a binary tree

#### Pre-order traversal
- Print the data at the root
- Recursively print out all data in the left subtree
- Recursively print out all data in the right subtree
- Root → Left → Right

### Binary Search Tree (BST)
A Binary Search Tree (BST) is a node-based binary tree data structure that maintains elements in a strictly sorted order to allow for fast data retrieval, insertion, and deletion

#### Properties of BST
- Left Subtree: Every node in the left subtree has a value less than the parent node's value.
- Right Subtree: Every node in the right subtree has a value greater than the parent node's value.
- Recursive Rule: Both the left and right subtrees must also independently be valid Binary Search Trees.
- insertion, deletion can be performed in BST
- BST has a time complexity of O(log n) if the tree is balanced, but it has a time complexityof O(n) for unbalanced trees

#### Searching for a target value in BST
- Compare the value with the element in the root node.
- If the value is equal , the search is successful
- If value is less , search the left
- If value is greater , search the right
- If the subtree is empty , the search is unsuccessful.

#### Inserting a node in BST
- Initialize the current node with root node
- Compare the key with the current node.
- Move left if the key is less than or equal to the current node value.
- Move right if the key is greater than current node value.
- Repeat steps 2 and 3 until you reach a leaf node.
- Attach the new key as a left or right child based on the comparison with the leaf node’s value.

#### AVL Trees
- AVL is a self-balancing BST
- In AVL trees, the main property states that The difference between heights of left and right subtrees cannot be more than one for all nodes.”
- The Balance Factor (BF) for a node (X) is the difference in height between its right and left subtrees.
- The BF is checked after every insertion & deletion, do necessary rotations if out of balance
- Searching, insertion, and deletion are exactly the same as BST.

BF(X) = height(rightSubtree(X)) − height(leftSubtree(X))

Balance factor (BF) values
- 0: The node is in balance.
- more than 0: The node is "right heavy".
- less than 0: The node is "left heavy".

If BF < -1, or BF > 1, the tree is not balance. Hence, a tree rotation operation is needed.
