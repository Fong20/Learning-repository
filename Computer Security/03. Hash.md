# Hash
- Hash is a cryptographic technique that produces hash values using a hash function (algorithm).
- A hash function takes a variable sized input message and produces a fixed sized hash value output.
- The transformation of a string of characters into fixed-length hash value is usually shorter than the orignal message length.
- Eg: SHA 512 hash function takes for input messages of length up to 2^128 bits and produces as output a 512 bit message digest (MD).

Note: Message digest is also known as hash value

## Characteristics of hash
- A data object that maps to a pre-specified hash result (the one-way property)
- Two distinct data objects do not map to the same hash result (the collision-free property)

Because of these characteristics, hash functions are often used to check data integrity, whether the data has been altered. 

## Hash function requirements
This table lists the generally accepted requirements for a cryptographic hash function. 

1. Varaible input size = hash function can be applied to any input size
2. Fixed output size = hash function produces a fixed output size
3. Efficiency = efficient in hardware and software requirements to compute the hash value
4. Preimage resistant = one-way property. The original data cannot be recalculated / obtained from the hash value
5. Second preimage resistant (weak collision resistant) = Given a specific input, it is computationally infeasible to find a different input that generates the exact same hash.
6. Collision resistant = computationally infeasible to find two different input messages that generate the same hash value. 
7. Pseudorandomness =  property where hash outputs appear completely random, uniform, and unpredictable to anyone who doesn't know the input

- The first three properties are requirements for the practical application of a hash function.
- A hash function that satisfies the first five properties in the Table is referred to as a weak hash function.
- If the sixth property, collision resistant, is also satisfied, then it is referred to as a strong hash function.

## Applications of Hash
1. Message Authentication
2. Digital Signatures
3. One-way password file
4. Intrusion detection and virus detection
5. Pseudorandom function (PRF) and Pseudorandom number generator (PRNG)

### Message Authentication
- Message authentication is a procedure to allow parties to verify that received message is authentic (content is not altered and source is authentic).
- When a hash function is used to provide message authentication, the hash function value is often referred to as a message digest.
- Message authentication protects against active attacks.

#### How it works
1. The sender computes a hash value using the bits in the message and transmits both the hash value and the message.
2. The receiver performs the same hash calculation on the message bits and compares this value with the incoming hash value.
3. If there is a mismatch, the receiver knows that the message (or possibly the hash value) has been altered.

#### Vulnerabilities and Solutions
However, such method is still vulerable to MITM attacks. 

1. Alice transmits a data block and attaches a hash value.
2. Darth intercepts the message, alters or replaces the data block, and calculates and attaches a new hash value.
3. Bob receives the altered data with the new hash value and does not detect the change.

### Digital Signatures
A digital signature hash is a cryptographic "fingerprint" of a document that is encrypted with a sender's private key. Instead of signing an entire document, the system calculates a unique hash, which is then signed. This ensures the integrity and authenticity.

#### How it works
- The operation of the digital signature is similar to that of the message authentication. 
- In the case of the digital signature, the hash value of a message is encrypted with a user’s private key.
- Anyone who knows the user’s public key can verify the integrity of the message that is associated with the digital signature.
